📋 WHAT YOU NEED (5 MINUTES)
───────────────────────────────────────────────────────────────────

1. MODEL_ACCESS_KEY from DigitalOcean
   
   Get it here:
   https://cloud.digitalocean.com/agent-platform/serverless-inference
   
   Steps:
   - Login to DigitalOcean
   - Go to "Agent Platform" → "Serverless Inference"
   - Scroll to "Model Access Keys"
   - Click "Create Access Key"
   - Copy the key (shown only once!)

───────────────────────────────────────────────────────────────────
🚀 QUICK START (5 MINUTES)
───────────────────────────────────────────────────────────────────

1. Install dependencies:
   
   cd cursivis-gradient/backend/gradient-agent
   npm install

2. Configure environment:
   
   cp .env.example .env
   notepad .env
   
   Add your key:
   MODEL_ACCESS_KEY=your_key_here

3. Start the server:
   
   node src/server.js
   
   You should see:
   [startup] ✓ DigitalOcean Gradient AI connection OK
   [gradient-agent] Listening on http://127.0.0.1:8080

4. Test it:
   
   curl -X POST http://localhost:8080/agent \
     -H "Content-Type: application/json" \
     -d "{\"text\":\"Hello DigitalOcean!\",\"mode\":\"smart\"}"
